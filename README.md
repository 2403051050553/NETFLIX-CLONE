# Netflix-Inspired Landing Page

A static streaming-service landing page concept with a hero banner, email-entry call to action, feature sections, and FAQ-style content.

## Built with

- HTML (`index.htm`)
- CSS (`styles.css`)

## Run locally

Open `index.htm` in a modern browser. The page references `src/styles.css`, while the stylesheet in this repository is at the root as `styles.css`; correct that path for the authored styles to load. Images, video, fonts, and icons also depend on external URLs.

## Scope

This is a front-end design exercise inspired by streaming landing pages. It is not affiliated with Netflix and does not provide accounts, subscriptions, or video playback.
